## 1. 第一轮：先看界面（约 2 分钟）

| # | 操作 | 期望 |
| --- | --- | --- |
| 1.1 | 打开首页 | 标题「慧记」、副标题、**待处理草稿那一行**、账本 / 报表 / 设置三个按钮、底下一段「试试：…」 |
| 1.2 | 看**最底部** | 一条输入栏：左边输入框（灰底圆角）、右边一个麦克风图标 + 一个**紫色圆形上箭头** |
| 1.3 | 点一下输入框 | 键盘弹起，**输入栏被顶到键盘正上方，不能挡住**（这条是真机重点，见下方说明） |
| 1.4 | 输入框留空，点上箭头 | 提示「先写一句要记的账」 |
| 1.5 | 点麦克风图标 | 输入框换成「点一下开始说话」，麦克风图标变成键盘图标；再点图标切回文字 |
| 1.6 | 点「设置」 | 表单打开，**已预选好**：存疑才确认 / 阈值 300 / 标准 / **DeepSeek 官方** |
| 1.7 | 看设置页底部状态行 | 应显示**已有可用的 Key**（包里编进去了） |

> 服务商是「**跟着实际配了 Key 的那家走**」的：`local.properties` 里配的是
> `wisebook.deepseek.key`，所以默认就是 DeepSeek 官方、模型 `deepseek-chat`，
> 不需要同时记着去改代码。两家都没配 Key 时才退回硅基流动、并提示去设置页填。
> （见 `LlmConfigStore.provider()`；换服务商只改一个枚举值，D2 §6.2）

**1.3 为什么是真机重点：** `windowSoftInputMode="adjustResize"` 在全面屏下**不生效**
——`EdgeToEdge` 关掉了系统的自动让位，键盘会直接盖在内容上。这条配置看着完全正确，
只有"键盘弹起时看一眼"才能发现。已在模拟器上验过，但你的机器键盘可能更高。

**1.4~1.6 这几步还顺带验老系统兼容：** 项目里曾大量使用 `List.of` / `Set.of` /
`List.copyOf` / `String.isBlank()`，而它们在 Android 上分别是 **API 30 / 31 / 33** 才有的，
`minSdk` 却是 26。这批调用已全部替换成等价写法，但**单测跑在 JDK 上、模拟器是 API 36，
两道防线都验不出老系统上的问题**。

- 你的机器是 **Android 8 ~ 12（API 26 ~ 32）** → 这一轮就是那批修复的真实验证
- 你的机器是 **Android 13+（API 33+）** → 那批 API 本来就有，验不出差异

## 3. 第三轮：该问的时候会问（约 3 分钟）

关键点：**触发确认的条件是「或」关系**——不只是金额大，存疑同样要问。

| # | 操作 | 期望 |
| --- | --- | --- |
| 3.1 | 输入 `今天买了台电脑 6800` | 结果行是「已生成草稿，等你确认」；点它进**确认页**，顶部一行「为什么要你核对」 |
| 3.2 | 输入 `买菜三十左右` | 同样进确认页，原因含「约数折算值」（D1 §5.2 条件 2：约数必须让人看一眼） |
| 3.3 | 输入 `买菜三百五` | 金额应为 **350 元**，而不是 305 元（D1 §1.1 那条经典规则） |
| 3.4 | 确认页上把金额改掉 → 点「保存修改并重新校验」 | 条件都满足时**直接落账**，不再多问一遍；还不满足则带着新问题再问 |
| 3.5 | 确认页上点「丢弃这笔」 | 账目不入库；「待处理草稿」数量减 1 |
| 3.6 | 输入 `给爸妈转了 660` | 分类落在 **人情**（不是「其他」）；**报表里默认计入本月支出** |
| 3.7 | 点「报表」→ 勾上「排除转账」 | 本月支出**当场变小**（减掉 660），「人情」那一行消失，提示变成「已排除 1 笔转账，合计 660.00 元」 |
| 3.8 | 账本里点任意一条 → 改正分类 | 确认页 / 账本 / 报表三处的分类**跟着一起变**（账目与草稿是同步改的） |

结果行里那行「模型调用 N 次」是有意留的：**首次就通过** vs **重试后才通过**，
一眼能看出那条「带错误反馈的修正型重试」有没有在工作。

## 5. 出问题了怎么反馈

最有用的是**三处文字**，截图发过来即可：

1. **结果行**——里面有「模型调用 N 次」，能直接区分「首次通过」与「重试后通过」，
   也能看出是模型输出不合格降级了，还是网络/鉴权出问题
2. **账目详情页 → 展开解析详情**——模型给了什么、分类是怎么定的、原始 JSON，一眼定位
3. **设置页底部状态行**——能看出 Key 到底有没有被认到

如果整个页面打不开或者闪退，把手机型号 + Android 版本告诉我，
再配合 `adb logcat` 抓一段（能连电脑的话）。
